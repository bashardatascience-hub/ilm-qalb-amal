# Ilm · Qalb · Amal — ইলম · কলব · আমল

A Bengali-first learning website with English versions, subject guides, a prayer-series introduction, local search, browser bookmarks and a PDF library.

**Website:** https://bashardatascience-hub.github.io/ilm-qalb-amal/

## Edit a lesson without editing the design

1. Open `content/bn/` for Bengali or `content/en/` for English on GitHub.
2. Open a `.md` file and select the pencil (Edit).
3. Edit the title, description and text. Keep the metadata between the `---` lines.
4. Select **Commit changes** to save to `main`.
5. The **Publish website** workflow builds, checks and publishes the site. See the Actions tab for status.

Use the same `slug` in both language folders to connect translations. A missing translation sends the language switch to that language's homepage.

## Add a new lesson

Copy `content/lesson-template.md` into the language folder, give it a unique filename, and replace every placeholder. Use a unique lowercase `slug` containing letters, numbers and hyphens. Select a valid `subject` from `data/subjects.json`.

`status: draft` excludes the file from publication. Change to `status: published` only after reviewing the content and sources. For the prayer series, use `series: praying-from-the-heart` and a numeric `order`. The series list and search index update during the build.

The Bengali prayer series contains the introduction and 18 lessons imported from the user's **অন্তর থেকে নামাজ পড়া** manuscript. All 54 source tables, Arabic passages, explanations, reflection questions and source references were retained. `data/manuscript.json` records the chapter mapping and source-file hash; the original Word file and private sharing link are not uploaded to the repository.

The manuscript has no separate lessons 7 or 11. The original numbering is retained; the wudu section between lessons 2 and 4 is presented as lesson 3. The English lesson pages identify the Bengali original and link to it; they are not full English translations. Set `translationPending: false` when an actual English translation is supplied.

## Add a PDF

Place an intended public PDF in `assets/pdfs/`, or use a public HTTPS URL. Add an entry to `data/resources.json`:

```json
[
  {
    "title": "Resource title",
    "description": "Author/source, topic and short description",
    "language": "bn",
    "url": "https://your-public-file-url.example/book.pdf"
  }
]
```

Languages: `bn`, `en`, or `both`. Use a real URL and check that it opens without an author login. For a repository PDF, the URL can be the full deployed URL ending in `/assets/pdfs/your-file.pdf`. Only upload material intended for public distribution. The repository and website are public. Keep large audio/PDF libraries on suitable external storage instead.

## Sections and translations

Subject names and descriptions are in `data/subjects.json`. Page layouts and bilingual interface text are generated by `scripts/build.mjs`. Presentation is in `assets/style.css`; client behaviour is in `assets/app.js`.

Saved lessons stay in the reader's browser. There is no account system or server database. Search covers published page titles and descriptions in the selected language. The site links to Quran.com; it does not embed an authenticated Quran API or contain secret API keys. Fonts are requested from Google Fonts, with system fallbacks.

## Run locally

Requires Node.js 24+.

```sh
npm ci
npm run build
npm run check
python -m http.server 4173 --directory dist
```

Then visit http://localhost:4173/ . For a project-path build, set `BASE_PATH=/ilm-qalb-amal`. Deployment derives the path automatically from GitHub Pages configuration. Set `SITE_URL` to the public site root if moving to another repository/domain.

## Deployment

The `.github/workflows/pages.yml` workflow runs on every push to `main`. In repository **Settings → Pages**, the publishing source is **GitHub Actions**. The build uploads only `dist/`; original workspace planning files are not included.

The default Bengali homepage is `/bn/`. English is `/en/`. Every published content page has a permanent path, language metadata and a sitemap entry. Submit corrections via this repository's Issues tab.
